Latent terms
============

Combine these terms in ``latent_fn`` to describe latent scores or trajectories.
Terms can also enter ``DIF`` to model item-specific effects. Configure priors
and sharing with :doc:`parameters`; see :doc:`custom` for user-defined terms.
